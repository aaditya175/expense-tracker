# Expense Tracker

A full-stack web application for tracking personal income and expenses.

## Tech Stack

- Python (Flask)
- SQLite
- Bootstrap 5

## Features

- Add income and expense transactions with type, category, amount, and date
- Real-time financial summary — Total Income, Total Expenses, Current Balance
- Complete transaction history
- Input validation on both client and server side
- Fully responsive across all devices

## Setup

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
